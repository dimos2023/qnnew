# Yangwang U8 360 viewer

This is a local 360-degree image-sequence viewer based on the official U8 exterior frames.

Run `start-local.ps1`, then open `http://127.0.0.1:8766/`.

The official page uses 24 rendered PNG frames per exterior color, not a GLB/GLTF geometry model. These assets can produce a smooth website configurator but cannot be edited as geometry in Blender.
